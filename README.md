# readable-lora.github.io

Project page for **Reading Documents out of Weight Updates: Hypernetwork-Written LoRA Adapters Linearly Encode Their Document** (Aryan Keluskar), an oral at the COLM 2026 Workshop on Context Beyond the Window.

- Paper: https://openreview.net/forum?id=Vsuhr8sbG8
- PDF: https://openreview.net/pdf?id=Vsuhr8sbG8
- Page: https://readable-lora.github.io/

The page is one static `index.html` with no build step. Figures are inline SVG drawn from the numbers reported in the paper and talk. `assets/og.mp4` and `assets/og.jpg` are the link-preview loop and still.

Preview locally:

```sh
python3 -m http.server 8000
```

Fonts in `assets/fonts/` are subsets of Literata, Schibsted Grotesk, IBM Plex Mono and Nanum Pen Script, all under the SIL Open Font License 1.1. The paper is licensed CC BY 4.0.
